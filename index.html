E7 Case Worker Application

Application Development · VB.NET · Oracle · Crystal Reports

Developed and maintained the E7 Case Worker application used in the NITK Academic Section for generating academic and administrative certificates.

  • Developed the application using VB.NET.
  • Used Oracle for maintaining and retrieving student data.
  • Used Crystal Reports for certificate and report generation.
  • Supported generation of Bonafide Certificates and Character Certificates.
  • Supported generation of Expenditure, Course Completion, Rank and CGPA Conversion Certificates.
  • Maintained student data for UG, PG and Ph.D. students.
